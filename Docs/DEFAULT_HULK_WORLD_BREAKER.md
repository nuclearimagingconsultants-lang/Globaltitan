# Default Hulk is World Breaker

Product name stays **Titan Streets**. The form label may say World Breaker.

## Rule

First transform / new game Hulk **is** World Breaker. It is not a weaker base that upgrades into World Breaker later. BalanceProfile `Legacy` vs `Worldbreaker_v1` still toggles Anger Loop **numbers** only — it does **not** gate the World Breaker form.

## Browser Maps+Hulk path

1. `hulkKind` / `lastTitan` default `worldbreaker`. Save `activeForm` default `WorldBreaker` on first transform.
2. Mesh presence: World Breaker mass (scale, smashed pavement pauldrons), HUD chip **BREAKER**.
3. Look: saturated green + bright red radiance + HD CGI (same physical bar as the old Savage kit).
4. Old saves with `savage` canonicalize to `worldbreaker`. Savage is an alias, not a starter form.
5. Other forms stay additive unlocks on top: Fixit / Red / Immortal / Maestro / Feral / Hell / Cosmic / Bruce variants. Do not strip Anger Loop or boss Kill/Spare unlocks.
